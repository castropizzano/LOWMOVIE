# Contribuição para a versão pública LowMovie™

Este repositório reúne uma versão pública de referência do portal. Consulte [LICENSE](LICENSE) antes de propor adaptações ou reutilizações.

Descreva o problema observado, a rota, o idioma e a mudança proposta. Alterações em conteúdo autoral, conceitos, créditos, imagens ou condições de uso dependem de decisão de Castro Pizzano e de fontes verificáveis.

Use mensagens de commit curtas que descrevam a mudança realizada. Preserve os créditos verdadeiros e mantenha a documentação focada na consulta e execução do projeto.

Execute as verificações adequadas ao escopo:

```sh
npm test
npm run build
```

Para alterações de interface, confira português e inglês, navegação por teclado e leitura em telas pequenas. Preserve a dissertação, os fac-símiles, os documentos e as mídias distribuídos. Atualizações desta versão são revisadas antes de sua publicação.
