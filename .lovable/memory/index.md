# Project Memory

## Core
Hallucination Zero: The PDF dissertation is the absolute authority. Never invent or extrapolate info.
Visuals: Fixed Dark mode. Use semantic theme tokens. Grayscale media (turns color on hover).
Typography: Manrope font. max-w-5xl container, text-justify for body text. 11px for micro-texts.
Tone: Academic, assertive. Prioritize institutional rigor over visual spectacle. Use 'é' instead of 'funciona como'.
Code Hygiene: Strict dark theme (no next-themes). No unused Shadcn components or npm deps. No AI-generated visuals.
i18n: Full PT/EN support using react-i18next.
Trademarks: LowMovie™, LowPressure™, Lowbyrinth™, Low Runner™ — always with ™ symbol.
