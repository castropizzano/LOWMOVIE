# LowMovie™ e o Labirinto Criativo

**Versão pública de referência do portal de pesquisa de Castro Pizzano.**

[Portal](https://lowmovie.lovable.app) · [Dissertação](https://doi.org/10.5281/zenodo.20619076) · [Condições de uso](LICENSE)

Reúno aqui uma versão de referência do código e dos materiais disponibilizados no portal LowMovie™. A pesquisa acompanha os processos criativos do filme realizado pelo coletivo LowPressure™, entre corpo, cidade, câmera e criação coletiva.

A dissertação documenta. O portal expande. O livro convida.

## Sobre esta versão

Este repositório publica uma seleção identificada de arquivos para consulta. Seu histórico começa com a disponibilização desta versão. As atualizações públicas são revisadas antes de sua inclusão.

Os materiais de pesquisa mantêm seus créditos e condições de uso. A consulta ao código e sua disponibilidade no GitHub não concedem autorização geral para reproduzir, modificar ou reutilizar os materiais. Adaptações dependem de autorização conforme [LICENSE](LICENSE).

## Executar localmente

Requisitos: Git, Node.js e npm.

```sh
git clone https://github.com/castropizzano/LOWMOVIE-public.git
cd LOWMOVIE-public
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Alguns documentos e mídias usam serviços externos. A execução local depende de conexão para carregá-los e não representa uma cópia integral de todos os acervos associados à pesquisa.

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Framer Motion · i18next.
